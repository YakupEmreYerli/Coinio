---
title: Telegram notifications
description: A daily message about upcoming and overdue payments.
---

Coinio sends one message a day through your own Telegram bot.

## Set it up

<Steps>
<Step>

In Telegram, talk to [@BotFather](https://t.me/BotFather), send `/newbot` and copy the **bot token** it gives you.

</Step>
<Step>

Send any message to your new bot (or add it to a group). Then open this address in a browser, with your token in it, and find `"chat":{"id":...}` in the answer:

```text
https://api.telegram.org/bot<your-token>/getUpdates
```

That number is the **chat ID**. Group IDs start with a minus sign.

</Step>
<Step>

In Coinio, open **Settings › Notifications**, paste the token and chat ID, pick the time to send at (default 09:00) and click **Send test message**.

</Step>
</Steps>

The token is stored in the database and shown masked (`****` and the last four characters) afterwards. Leave the field as it is to keep the saved token.

You can also set both values as [environment variables](/docs/reference/configuration), `COINIO_TELEGRAM_BOT_TOKEN` and `COINIO_TELEGRAM_CHAT_ID`. When set, they take priority over what is saved in the app.

## What the message says

Once a day, after the time you picked (in your time zone), Coinio sends a message with up to three parts:

- **Overdue:** manual payments whose date has passed, with how many days late.
- **Coming up:** payments within each subscription's **Remind me** window (1 day before by default, set per subscription from 0 to 30). Automatic ones read "will be charged tomorrow", manual ones "due in 3 days".
- **Charged today:** automatic payments recorded today.

If none of these has anything, no message is sent that day. Paused subscriptions are never included. The message is in the app's language.

If Telegram cannot be reached, Coinio tries again every minute for the rest of the day.
