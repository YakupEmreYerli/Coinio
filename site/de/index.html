Installieren

Open-Source-Abo-Verwaltung

Alle Abos,
eine ruhige Seite.

Coinio behält im Blick, wofür Sie zahlen, warnt Sie vor jeder Verlängerung und läuft auf Ihrem eigenen Server. Ihre Daten verlassen ihn nie.

curl -fsSL https://getcoinio.me/install | sh

Prüft, ob Docker vorhanden ist, startet Coinio auf Port 8080 und bietet einen Cloudflare Tunnel für https an. Skript ansehen

docker run -d --name coinio --restart unless-stopped \
  -p 8080:8080 -v coinio-data:/data \
  ghcr.io/yakupemreyerli/coinio:latest

Öffnen Sie dann http://your-server:8080 und erstellen Sie Ihr Konto. Images für amd64 und arm64.

mkdir coinio && cd coinio
curl -fsSLO https://raw.githubusercontent.com/yakupemreyerli/coinio/main/docker-compose.yml
docker compose up -d

Die Daten landen in ./data neben der Datei. Setzen Sie TZ in einer .env-Datei auf Ihre Zeitzone (z. B. Europe/Berlin).

# Project › Create Service › Compose › Git
Repository   https://github.com/yakupemreyerli/coinio
Branch       main
Compose path ./docker-compose.yml

Deployen Sie und fügen Sie dann eine Domain auf Port 8080 hinzu. Eine Dokploy-Vorlage für die Ein-Klick-Installation ist in Arbeit.

curl -fsSL -o /boot/config/plugins/dockerMan/templates-user/coinio.xml \
  https://raw.githubusercontent.com/yakupemreyerli/coinio/main/deploy/unraid/coinio.xml

Im Unraid-Terminal ausführen, dann Docker › Add Container › Template › Coinio.

FAQ

Fragen, Antworten.

Was Leute fragen, bevor sie Coinio auf ihren Server bringen. Fehlt etwas? Eröffnen Sie ein Issue.

Ist Coinio kostenlos? Unter welcher Lizenz?

Ja. Coinio ist Open Source unter der MIT-Lizenz. Es gibt keine Bezahlversion und kein Konto bei uns; Sie betreiben es, es gehört Ihnen. Der Code liegt auf GitHub.

Was brauche ich, um es zu betreiben?

Einen Rechner mit Docker: einen VPS, einen Heimserver, ein NAS oder einen Raspberry Pi. Images gibt es für amd64 und arm64. Eine separate Datenbank ist nicht nötig, und im Leerlauf braucht Coinio etwa 60 MB Arbeitsspeicher.

Wo liegen meine Daten, und wie sichere ich sie?

Alles liegt im Ordner /data des Containers: eine SQLite-Datei (coinio.db) und die Logos, die Sie ausgewählt haben. Sichern Sie dieses Volume, und Sie haben alles. Beim Installationsskript oder mit docker run heißt das Volume coinio-data:

docker run --rm -v coinio-data:/data -v "$PWD":/backup alpine \
                tar czf /backup/coinio-backup.tgz -C /data .

Mit Compose ist es der Ordner ./data neben der Datei. Sie können Ihre Abos und Zahlungen in der App außerdem als CSV oder JSON herunterladen.

Wie bekomme ich HTTPS und öffne Coinio auf dem Handy?

Das Installationsskript bietet einen Cloudflare Tunnel an: Tunnel-Token einfügen, und Coinio bekommt eine https-Adresse, ohne dass Sie Ports öffnen müssen. Wenn Sie bereits einen Reverse Proxy nutzen (Caddy, Traefik, Nginx, Dokploy), leiten Sie stattdessen eine Domain auf Port 8080.

In beiden Fällen setzen Sie COINIO_PUBLIC_URL auf diese https-Adresse. Der claude.ai-Konnektor und sichere Cookies brauchen sie.

Wie funktionieren Updates?

Neues Image laden und den Container neu erstellen. Ihre Daten bleiben im Volume, Datenbankänderungen werden beim Start angewendet. Mit Compose ist das docker compose pull && docker compose up -d. Mit docker run laden Sie das Image, entfernen den alten Container und führen denselben Befehl erneut aus.

Sendet Coinio Daten nach Hause? Woher kommen die Wechselkurse?

Keine Telemetrie, keine Analyse, kein Konto. Die Wechselkurse kommen einmal täglich von Frankfurter, das die Referenzkurse der Europäischen Zentralbank veröffentlicht, und nur für die Währungen, die Sie nutzen.

Die übrigen Anfragen nach außen passieren nur, weil Sie sie auslösen: das Icon einer Website laden, die Sie hinzufügen, und Telegram-Erinnerungen, falls Sie sie einrichten.

Kann meine Familie es nutzen?

Jede Installation hat ein Konto, und ein Haushalt kann es gemeinsam nutzen, um alle Rechnungen an einem Ort zu haben. Wenn zwei Personen getrennte Daten möchten, starten Sie einen zweiten Container auf einem anderen Port; das ist ein einziger weiterer Befehl.

Kann ich aus einer anderen App importieren?

Aus Wallos ja: Exportieren Sie dort Ihre Abos als JSON und laden Sie die Datei unter Einstellungen › Import. Sie sehen eine Vorschau und eventuelle Warnungen, bevor etwas gespeichert wird.

Von überall sonst geht das Hinzufügen von Hand schnell: Bei 161 bekannten Diensten werden Logo, Kategorie und Abrechnungszeitraum beim Tippen ausgefüllt. Oder Sie verbinden Claude und lassen die Abos von Claude anlegen.

Welche Sprachen spricht Coinio?

Die App gibt es auf Englisch, Türkisch, Deutsch, Französisch, Spanisch, brasilianischem Portugiesisch, vereinfachtem Chinesisch und Japanisch. Sie startet in der Sprache Ihres Browsers, und Sie können sie jederzeit in den Einstellungen wechseln. Datumsangaben, Beträge und Währungen werden passend zur gewählten Sprache formatiert.

Was ist MCP, und wie verbinden sich Claude oder ChatGPT?

MCP (Model Context Protocol) ist ein offener Standard, mit dem KI-Assistenten Werkzeuge nutzen können. Coinio stellt unter /mcp einen MCP-Server bereit, sodass ein Assistent auflisten kann, was sich diese Woche verlängert, ein Abo hinzufügen oder eine Rechnung als bezahlt markieren kann.

Fügen Sie auf claude.ai oder in der Claude-App einen benutzerdefinierten Konnektor mit Ihrer Coinio-Adresse hinzu und melden Sie sich an; ein Schlüssel ist nicht nötig. Claude Code, Claude Desktop und Cursor verwenden einen API-Schlüssel aus den Einstellungen. Die benutzerdefinierten Konnektoren von ChatGPT nehmen dieselbe Adresse. Für all das brauchen Sie die https-Adresse von oben.

Gibt es eine iPhone-App?

Nicht im App Store. Es gibt ein kostenloses Scriptable-Widget für Home- und Sperrbildschirm, das Ihre anstehenden Zahlungen mit einem Schlüssel mit Lesezugriff abruft und offline die zuletzt geladenen Daten weiter anzeigt. Die Web-App lässt sich außerdem zum Home-Bildschirm hinzufügen und öffnet sich dann wie eine App.

Warum keine Tabelle?

Eine Tabelle speichert Beträge, aber sie schiebt keine Fälligkeiten weiter, rechnet Währungen nicht täglich um und sagt Ihnen nicht am Dienstag, dass sich am Freitag etwas verlängert. Coinio erledigt das, erfasst automatische Abbuchungen von selbst und führt einen Verlauf, den Sie auswerten können.
