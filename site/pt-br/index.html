Instalar

Controle de assinaturas de código aberto

Todas as assinaturas,
numa página tranquila.

O Coinio acompanha tudo o que você paga, avisa antes de qualquer renovação e roda no seu próprio servidor. Seus dados nunca saem de lá.

curl -fsSL https://getcoinio.me/install | sh

Verifica se o Docker está instalado, sobe o Coinio na porta 8080 e oferece um Cloudflare Tunnel para ter https. Ler o script

docker run -d --name coinio --restart unless-stopped \
  -p 8080:8080 -v coinio-data:/data \
  ghcr.io/yakupemreyerli/coinio:latest

Depois abra http://your-server:8080 e crie sua conta. Imagens para amd64 e arm64.

mkdir coinio && cd coinio
curl -fsSLO https://raw.githubusercontent.com/yakupemreyerli/coinio/main/docker-compose.yml
docker compose up -d

Os dados ficam em ./data, ao lado do arquivo. Defina TZ com o seu fuso horário (ex.: America/Sao_Paulo) num arquivo .env.

# Project › Create Service › Compose › Git
Repository   https://github.com/yakupemreyerli/coinio
Branch       main
Compose path ./docker-compose.yml

Faça o deploy e adicione um domínio na porta 8080. Um template do Dokploy com um clique está a caminho.

curl -fsSL -o /boot/config/plugins/dockerMan/templates-user/coinio.xml \
  https://raw.githubusercontent.com/yakupemreyerli/coinio/main/deploy/unraid/coinio.xml

Rode no terminal do Unraid e depois vá em Docker › Add Container › Template › Coinio.

O que ele faz

App pequeno. Dá conta de todas as contas.

Lembretes antes da cobrança

Todos os vencimentos num só calendário. Uma mensagem no Telegram chega alguns dias antes de qualquer renovação, para nada pegar você de surpresa.

Qualquer moeda

Netflix em reais, ChatGPT em dólar, hospedagem em euro. A cotação do dia junta tudo num total só, na sua moeda.

161 serviços prontos

Digite "spot" e o Spotify aparece com logo, categoria e ciclo de cobrança. Os outros serviços ganham o ícone do próprio site.

Pergunte ao Claude ou ao ChatGPT

Um servidor MCP integrado, com OAuth. Pergunte "o que renova esta semana?" ou peça "marque o aluguel como pago" pelo claude.ai ou pelo celular.

Na sua Tela de Início

Um widget gratuito do Scriptable para a Tela de Início e a Tela Bloqueada do iPhone. Sem app da App Store, e funciona até offline.

Do seu jeito

Temas, cor de destaque, fontes, densidade, ordem dos cards. Adicione seu próprio CSS ou crie cards em HTML para a página inicial.

Dúvidas

Perguntas, respondidas.

O que as pessoas perguntam antes de colocar o Coinio no servidor. Faltou alguma coisa? Abra uma issue.

O Coinio é grátis? Qual é a licença?

Sim. O Coinio é código aberto, sob a licença MIT. Não existe plano pago nem conta com a gente: você roda, você é o dono. O código está no GitHub.

O que eu preciso para rodar?

Uma máquina com Docker: uma VPS, um servidor em casa, um NAS ou um Raspberry Pi. As imagens são feitas para amd64 e arm64. Não há banco de dados separado para manter, e ele fica em uns 60 MB de memória quando ocioso.

Onde ficam meus dados e como faço backup?

Tudo fica na pasta /data do contêiner: um arquivo SQLite (coinio.db) e os logos que você escolheu. Faça backup desse volume e você tem tudo. Com o script de instalação ou com docker run, o volume se chama coinio-data:

docker run --rm -v coinio-data:/data -v "$PWD":/backup alpine \
                tar czf /backup/coinio-backup.tgz -C /data .

Com o Compose, é a pasta ./data ao lado do arquivo. Você também pode baixar suas assinaturas e pagamentos em CSV ou JSON pelo app.

Como tenho HTTPS e abro no celular?

O script de instalação oferece um Cloudflare Tunnel: cole o token do túnel e o Coinio ganha um endereço https sem abrir nenhuma porta. Se você já usa um proxy reverso (Caddy, Traefik, Nginx, Dokploy), aponte um domínio para a porta 8080.

Nos dois casos, defina COINIO_PUBLIC_URL com esse endereço https. O conector do claude.ai e os cookies seguros precisam dele.

Como funcionam as atualizações?

Baixe a imagem nova e recrie o contêiner. Seus dados continuam no volume, e as mudanças no banco de dados são aplicadas na inicialização. Com o Compose, é docker compose pull && docker compose up -d. Com docker run, baixe a imagem, remova o contêiner antigo e rode o mesmo comando de novo.

Ele envia dados para fora? De onde vêm as cotações?

Sem telemetria, sem analytics, sem conta. As cotações chegam uma vez por dia do Frankfurter, que publica as taxas de referência do Banco Central Europeu, e só para as moedas que você usa.

As outras chamadas externas acontecem porque você pediu: buscar o ícone de um site que você adicionou e enviar os lembretes do Telegram, se você configurar.

Minha família pode usar?

Cada instalação tem uma conta, e a casa toda pode compartilhá-la para manter as contas num só lugar. Se duas pessoas quiserem dados separados, rode um segundo contêiner em outra porta; é só mais um comando.

Posso importar de outro app?

Do Wallos, sim: exporte suas assinaturas lá em JSON e carregue o arquivo em Configurações › Importar. Você vê uma prévia e os avisos antes de qualquer coisa ser salva.

De qualquer outro lugar, adicionar à mão é rápido: 161 serviços populares preenchem logo, categoria e ciclo de cobrança enquanto você digita. Ou conecte o Claude e peça para ele adicionar por você.

Em quais idiomas ele está?

O app está em inglês, turco, alemão, francês, espanhol, português do Brasil, chinês simplificado e japonês. Ele abre no idioma do seu navegador e você pode trocar quando quiser em Configurações. Datas, valores e moedas seguem o formato do idioma escolhido.

O que é MCP e como o Claude ou o ChatGPT se conectam?

MCP (Model Context Protocol) é um padrão aberto que permite que assistentes de IA usem ferramentas. O Coinio oferece um em /mcp, então um assistente pode listar o que renova esta semana, adicionar uma assinatura ou marcar uma conta como paga.

No claude.ai ou no app do Claude para celular, adicione um conector personalizado com o endereço do seu Coinio e entre na conta; não precisa de chave. O Claude Code, o Claude Desktop e o Cursor usam uma chave de API criada em Configurações. Os conectores personalizados do ChatGPT aceitam o mesmo endereço. Tudo isso precisa do endereço https lá de cima.

Tem app para iPhone?

Não na App Store. Existe um widget do Scriptable gratuito para a Tela de Início e a Tela Bloqueada, que lê seus próximos pagamentos com uma chave somente leitura e continua mostrando os últimos dados quando está offline. O app web também pode ser adicionado à Tela de Início, onde abre como um app.

Por que não uma planilha?

Uma planilha guarda valores, mas não avança os vencimentos, não converte moedas todo dia e não avisa na terça que algo renova na sexta. O Coinio faz isso, registra as cobranças automáticas sozinho e guarda um histórico que vira relatório.
