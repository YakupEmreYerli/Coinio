インストール

オープンソースのサブスク管理

すべてのサブスクを、
落ち着いた1ページに。

Coinio は支払っているものを記録し、更新の前にお知らせします。動くのは自分のサーバーの上だけ。データが外に出ることはありません。

curl -fsSL https://getcoinio.me/install | sh

Docker の有無を確認し、ポート 8080 で Coinio を起動します。https 用に Cloudflare Tunnel の設定も案内します。 スクリプトを読む

docker run -d --name coinio --restart unless-stopped \
  -p 8080:8080 -v coinio-data:/data \
  ghcr.io/yakupemreyerli/coinio:latest

起動したら http://your-server:8080 を開き、アカウントを作成してください。amd64 と arm64 のイメージがあります。

mkdir coinio && cd coinio
curl -fsSLO https://raw.githubusercontent.com/yakupemreyerli/coinio/main/docker-compose.yml
docker compose up -d

データはファイルと同じ場所の ./data に保存されます。.env ファイルで TZ を自分のタイムゾーン（例：Asia/Tokyo）に設定してください。

# Project › Create Service › Compose › Git
Repository   https://github.com/yakupemreyerli/coinio
Branch       main
Compose path ./docker-compose.yml

デプロイしたら、ポート 8080 にドメインを追加してください。ワンクリックで使える Dokploy テンプレートも準備中です。

curl -fsSL -o /boot/config/plugins/dockerMan/templates-user/coinio.xml \
  https://raw.githubusercontent.com/yakupemreyerli/coinio/main/deploy/unraid/coinio.xml

Unraid のターミナルで実行し、Docker › Add Container › Template › Coinio を選びます。

ほかの導入先 CasaOS· Portainer· Coolify 近日対応· PikaPods 近日対応

ライブデモ

触ってみてください。本物のアプリです。

支払い済みにする、サブスクを追加する、カレンダーを開く。サンプルデータを使ってブラウザ内で動き、いつでもリセットできます。

新しいタブで開く
coinio · サンプルデータ
ライブデモを開く

サンプルデータは米ドルです。変更はこのブラウザタブの中だけに残ります。Telegram、API キー、インポートを使うには自分のサーバーが必要です。

できること

小さなアプリで、支払いをまるごと管理。

引き落とし前にお知らせ

すべての期限日を1つのカレンダーに。更新の数日前に Telegram にメッセージが届くので、思わぬ請求に驚くことはありません。

どの通貨でも

Netflix は円、ChatGPT はドル、サーバー代はユーロ。毎日の為替レートで、すべてを自分の通貨の合計にまとめます。

161のサービスを内蔵

「spot」と入力すれば、Spotify のロゴ、カテゴリ、請求サイクルが自動で入ります。それ以外のサービスは、そのサイトのアイコンを使います。

Claude や ChatGPT に聞く

OAuth 対応の MCP サーバーを内蔵。claude.ai やスマートフォンから「今週更新されるのは？」「家賃を支払い済みにして」と頼めます。

ホーム画面にも

iPhone のホーム画面とロック画面に置ける、無料の Scriptable ウィジェット。App Store のアプリは不要で、オフラインでも表示されます。

自分好みに

テーマ、アクセントカラー、フォント、表示密度、カードの並び順。独自の CSS を加えたり、ホーム画面用の HTML カードを書いたりもできます。

よくある質問

よくある質問に、お答えします。

Coinio をサーバーに入れる前によく聞かれることです。載っていない質問は Issue を作成してください。

Coinio は無料ですか？ライセンスは？

はい、無料です。Coinio は MIT ライセンスのオープンソースです。有料プランも、こちらへのアカウント登録もありません。自分で動かし、自分で所有します。コードは GitHub にあります。

動かすには何が必要ですか？

Docker が動くマシンです。VPS、自宅サーバー、NAS、Raspberry Pi のいずれでも構いません。イメージは amd64 と arm64 向けに用意しています。別途データベースを動かす必要はなく、待機時のメモリ使用量は約 60 MB です。

データはどこに保存されますか？バックアップの方法は？

すべてコンテナの /data フォルダにあります。SQLite ファイル1つ（coinio.db）と、選んだロゴだけです。このボリュームをバックアップすれば、すべてが残ります。インストールスクリプトか docker run を使った場合、ボリューム名は coinio-data です。

docker run --rm -v coinio-data:/data -v "$PWD":/backup alpine \
                tar czf /backup/coinio-backup.tgz -C /data .

Compose の場合は、ファイルと同じ場所の ./data フォルダです。サブスクリプションと支払いは、アプリから CSV または JSON でダウンロードすることもできます。

HTTPS にしてスマートフォンで開くには？

インストールスクリプトが Cloudflare Tunnel の設定を案内します。トンネルトークンを貼り付けるだけで、ポートを開けずに Coinio に https のアドレスが付きます。すでにリバースプロキシ（Caddy、Traefik、Nginx、Dokploy）を使っている場合は、ドメインをポート 8080 に向けてください。

どちらの場合も、COINIO_PUBLIC_URL にその https アドレスを設定してください。claude.ai のコネクタと安全な Cookie に必要です。

アップデートはどうすればいいですか？

新しいイメージを取得して、コンテナを作り直します。データはボリュームに残り、データベースの変更は起動時に適用されます。Compose なら docker compose pull && docker compose up -d です。docker run の場合は、イメージを取得し、古いコンテナを削除してから、同じコマンドをもう一度実行します。

外部にデータを送信しますか？為替レートはどこから？

テレメトリーも、アクセス解析も、アカウント登録もありません。為替レートは、欧州中央銀行の参照レートを公開している Frankfurter から1日1回、使っている通貨の分だけ取得します。

それ以外の外部への通信は、自分で求めたときだけです。追加したウェブサイトのアイコンの取得と、設定した場合の Telegram リマインダーです。

家族でも使えますか？

1つのインストールにつきアカウントは1つです。家族で共有すれば、すべての支払いを1か所で管理できます。データを分けたい場合は、別のポートで2つ目のコンテナを動かしてください。コマンドを1つ追加するだけです。

ほかの管理アプリから移行できますか？

Wallos からは移行できます。Wallos でサブスクリプションを JSON でエクスポートし、そのファイルを「設定 › インポート」で読み込んでください。保存する前に、プレビューと警告を確認できます。

それ以外からの場合も、手動ですぐに追加できます。主要な161のサービスは、入力するだけでロゴ、カテゴリ、請求サイクルが入ります。Claude を連携して、追加を頼むこともできます。

対応している言語は？

アプリは英語、トルコ語、ドイツ語、フランス語、スペイン語、ポルトガル語（ブラジル）、簡体字中国語、日本語に対応しています。最初はブラウザの言語で表示され、設定からいつでも切り替えられます。日付、金額、通貨は選んだ言語に合わせて表示されます。

MCP とは？Claude や ChatGPT とはどう連携しますか？

MCP（Model Context Protocol）は、AI アシスタントがツールを使えるようにするオープンな標準です。Coinio は /mcp で MCP サーバーを提供しているので、アシスタントが今週更新されるものを一覧にしたり、サブスクリプションを追加したり、支払い済みにしたりできます。

claude.ai や Claude モバイルアプリでは、Coinio のアドレスでカスタムコネクタを追加してサインインするだけです。キーは要りません。Claude Code、Claude Desktop、Cursor では、設定で作成した API キーを使います。ChatGPT のカスタムコネクタにも同じアドレスを使えます。いずれも、上で説明した https のアドレスが必要です。

iPhone アプリはありますか？

App Store にはありません。代わりに、ホーム画面とロック画面に置ける無料の Scriptable ウィジェットがあります。閲覧専用のキーで今後の支払いを読み込み、オフラインでも最後のデータを表示し続けます。ウェブアプリをホーム画面に追加すれば、アプリのように開くこともできます。

スプレッドシートではだめですか？

スプレッドシートは金額を記録できますが、期限日を自動で先に進めたり、毎日通貨を換算したり、金曜に更新されるものを火曜に知らせたりはしてくれません。Coinio はそれをすべて行い、自動引き落としも自動で記録し、レポートに使える履歴を残します。
