Gestionnaire d’abonnements open source

Tous vos abonnements,
sur une seule page.

Coinio suit ce que vous payez, vous prévient avant chaque renouvellement et tourne sur votre propre serveur. Vos données n’en sortent jamais.

curl -fsSL https://getcoinio.me/install | sh

Vérifie la présence de Docker, lance Coinio sur le port 8080 et propose un Cloudflare Tunnel pour le https. Lire le script

docker run -d --name coinio --restart unless-stopped \
  -p 8080:8080 -v coinio-data:/data \
  ghcr.io/yakupemreyerli/coinio:latest

Ouvrez ensuite http://your-server:8080 et créez votre compte. Images pour amd64 et arm64.

mkdir coinio && cd coinio
curl -fsSLO https://raw.githubusercontent.com/yakupemreyerli/coinio/main/docker-compose.yml
docker compose up -d

Les données sont enregistrées dans ./data, à côté du fichier. Indiquez votre fuseau horaire dans TZ (par ex. Europe/Paris) dans un fichier .env.

# Project › Create Service › Compose › Git
Repository   https://github.com/yakupemreyerli/coinio
Branch       main
Compose path ./docker-compose.yml

Déployez, puis ajoutez un domaine sur le port 8080. Un modèle Dokploy en un clic arrive bientôt.

curl -fsSL -o /boot/config/plugins/dockerMan/templates-user/coinio.xml \
  https://raw.githubusercontent.com/yakupemreyerli/coinio/main/deploy/unraid/coinio.xml

Lancez la commande dans le terminal Unraid, puis Docker › Add Container › Template › Coinio.

FAQ

Vos questions, nos réponses.

Ce qu’on nous demande avant d’installer Coinio sur son serveur. Il manque quelque chose ? Ouvrez une issue.

Coinio est-il gratuit ? Sous quelle licence ?

Oui. Coinio est open source, sous licence MIT. Il n’y a ni offre payante ni compte chez nous : vous l’hébergez, il vous appartient. Le code est sur GitHub.

De quoi ai-je besoin pour le faire tourner ?

D’une machine avec Docker : un VPS, un serveur maison, un NAS ou un Raspberry Pi. Les images sont compilées pour amd64 et arm64. Aucune base de données séparée à gérer, et au repos il consomme environ 60 Mo de mémoire.

Où sont stockées mes données, et comment les sauvegarder ?

Tout se trouve dans le dossier /data du conteneur : un fichier SQLite (coinio.db) et les logos que vous avez choisis. Sauvegardez ce volume et vous avez tout. Avec le script d’installation ou docker run, le volume s’appelle coinio-data :

docker run --rm -v coinio-data:/data -v "$PWD":/backup alpine \
                tar czf /backup/coinio-backup.tgz -C /data .

Avec Compose, c’est le dossier ./data à côté du fichier. Vous pouvez aussi télécharger vos abonnements et paiements en CSV ou JSON depuis l’application.

Comment avoir le HTTPS et l’ouvrir sur mon téléphone ?

Le script d’installation propose un Cloudflare Tunnel : collez un jeton de tunnel et Coinio obtient une adresse https sans ouvrir de port. Si vous utilisez déjà un reverse proxy (Caddy, Traefik, Nginx, Dokploy), pointez plutôt un domaine vers le port 8080.

Dans les deux cas, renseignez cette adresse https dans COINIO_PUBLIC_URL. Le connecteur claude.ai et les cookies sécurisés en ont besoin.

Comment se font les mises à jour ?

Récupérez la nouvelle image et recréez le conteneur. Vos données restent dans le volume, et les changements de base de données s’appliquent au démarrage. Avec Compose, c’est docker compose pull && docker compose up -d. Avec docker run, récupérez l’image, supprimez l’ancien conteneur et relancez la même commande.

Envoie-t-il des données quelque part ? D’où viennent les taux de change ?

Pas de télémétrie, pas de statistiques d’usage, pas de compte. Les taux de change sont récupérés une fois par jour auprès de Frankfurter, qui publie les taux de référence de la Banque centrale européenne, et uniquement pour les devises que vous utilisez.

Les autres requêtes extérieures n’ont lieu qu’à votre demande : récupérer l’icône d’un site que vous ajoutez, et envoyer les rappels Telegram si vous les avez configurés.

Ma famille peut-elle l’utiliser ?

Chaque installation a un seul compte, qu’un foyer peut partager pour garder toutes ses factures au même endroit. Si deux personnes veulent des données séparées, lancez un second conteneur sur un autre port : une commande de plus suffit.

Puis-je importer depuis un autre gestionnaire ?

Depuis Wallos, oui : exportez-y vos abonnements en JSON et chargez le fichier dans Paramètres › Importer. Vous voyez un aperçu et les éventuels avertissements avant tout enregistrement.

Depuis ailleurs, l’ajout manuel est rapide : 161 services courants remplissent leur logo, leur catégorie et leur fréquence pendant la saisie. Vous pouvez aussi connecter Claude et lui demander de les ajouter pour vous.

Dans quelles langues est-il disponible ?

L’application existe en anglais, turc, allemand, français, espagnol, portugais du Brésil, chinois simplifié et japonais. Elle démarre dans la langue de votre navigateur et vous pouvez en changer à tout moment dans Paramètres. Dates, montants et devises sont mis en forme selon la langue choisie.

Qu’est-ce que MCP, et comment Claude ou ChatGPT s’y connectent-ils ?

MCP (Model Context Protocol) est un standard ouvert qui permet aux assistants IA d’utiliser des outils. Coinio en fournit un sur /mcp : un assistant peut ainsi lister ce qui se renouvelle cette semaine, ajouter un abonnement ou marquer une facture comme payée.

Dans claude.ai ou l’application mobile Claude, ajoutez un connecteur personnalisé avec l’adresse de votre Coinio et connectez-vous ; aucune clé nécessaire. Claude Code, Claude Desktop et Cursor utilisent une clé API créée dans Paramètres. Les connecteurs personnalisés de ChatGPT acceptent la même adresse. Tout cela nécessite l’adresse https vue plus haut.

Existe-t-il une application iPhone ?

Pas sur l’App Store. Il existe un widget Scriptable gratuit pour l’écran d’accueil et l’écran verrouillé : il lit vos prochains paiements avec une clé en lecture seule et continue d’afficher les dernières données hors ligne. L’application web peut aussi être ajoutée à l’écran d’accueil, où elle s’ouvre comme une app.

Pourquoi pas un tableur ?

Un tableur garde les montants, mais il ne fait pas avancer les échéances, ne convertit pas les devises chaque jour et ne vous prévient pas le mardi qu’un abonnement se renouvelle le vendredi. Coinio le fait, enregistre tout seul les prélèvements automatiques et garde un historique sur lequel vous pouvez faire des rapports.
